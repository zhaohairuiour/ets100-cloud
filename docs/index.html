01

摘要

四个数字概括这次改版：删掉两个模块、关停三种本地读取、重写七处动画，编译错误为零。

0 模块整体移除
0 本地读取下线
0 动画重写
0 编译错误

改版前后的取舍只有一条标准：凡是能在云端拿到答案的路径保留并收敛，凡是依赖本机权限、漏洞或第三方账户的路径全部删除。 因此 data:account 与 feature:account 两个 Gradle 模块被整体移出， settings 中的 include 与六个模块的 project 依赖一并清理。

02

变更台账

八条记录，按改动顺序排列。点开任一条查看落到具体文件上的结果。

账户登录、个人中心、设备绑定、云端授权、头像与验证码入口原本集中在两个独立模块里，与云端读取链路并非强耦合，整体移除后主链路无需改写调用签名。

settings.gradle.kts 移除两个 include 六个模块的 project(":data:account") 依赖清零 导航图、首页入口、设置页账户区块同步删除

Shizuku、Root、漏洞直读三条链路共享同一套本地加载器与解析状态机；删除后 ActivationMode 只剩云端一项，激活页也不再需要权限申请流程。

ShizukuRuntimeState、RootManager、ZWCHelper 调用与权限申请移除 shizuku-api 依赖、DirectRead 面板、本地目录导出删除 首页状态条与引导卡片不再展示本地模式选项

阅读页从“多来源选择”退化为单一来源，PaperSource 只剩 Cloud 分支；加载、解析、模板合并、答案渲染全部走 ETS100ApiClient。

ETS100AuthManager：手机号 + 密码登录，持有 token 与 deviceCode CloudMerge / CloudTemplate：试卷模板合并 native 组件 libresolver.so、libcloud.so 保留

第一版改造把激活页做成了极简跳转页，与原始形态不符；随后从原始工程恢复手机号 + 密码表单与设备绑定短信验证弹窗，包名迁到 feature.activation。

CloudActivationScreen：账号、密码、协议勾选、提交态 DeviceVerificationDialog：设备绑定短信校验 ChangyanWebLoginActivity 保留为网页登录备用入口

原先在 graphicsLayer 里读取 animateFloatAsState 的普通 Float，每帧都在组合阶段取新值，导致整棵子树逐帧重组；换成 Animatable 后在 draw 阶段直读 .value，重组次数降为一次。

欢迎页 logo 用 spring 缩放，标题 / 特性 / CTA 按 160 – 560ms 延迟淡入上滑 运行模式页与完成页三段 stagger，步骤条用连续 scaleX 插值 步骤切换保留 slideInHorizontally + fadeIn

新增 StaggerEntrance 容器，按 index 延迟 45ms 步进、上限 8 项；LazyColumn 只对组合可见项生效，避免深列表长时间排队。

阅读页四态（gate / loading / error / list）统一接入 设置页内容块、引导完成页摘要卡同步使用 与弹簧、补间动画混用，节奏不互相打架

引导页三步高度不同，默认 SizeTransform 会裁切子内容，造成切换瞬间的跳变与文字截断；关闭裁剪后由布局自身承担高度变化。

SizeTransform(clip = false) 应用于步骤切换 onboarding → 主界面改为 alpha 0 → 1 淡入 显式声明 tween 时长，避免默认弹簧在长距离下过冲

仓库根写入 version.json（versionName / versionCode / apkUrl / notes / publishedAt），App 与站点共用；本页即 docs/ 下的静态站点，由 Pages 工作流发布。

站点请求顺序：同源 → ghproxy.net → gh-proxy.com → raw 直连 以 versionCode 数值比对为主，缺失时回退版本名字符串 纯静态，无框架、无构建步骤

    06

    构建与安装

    三条命令可复制。环境变量按本机路径替换。

    Toolchain
    $ export JAVA_HOME=/path/to/jdk-17 $ export ANDROID_HOME=/path/to/android-sdk $ export PATH=$ANDROID_HOME/platform-tools:$PATH
    Assemble
    $ ./gradlew :app:assembleDebug --no-daemon → app/build/outputs/apk/debug/app-debug.apk

    产物签名沿用 Android Debug 证书（SHA-256 79186029…d9c5）， 与历次交付包一致，可直接覆盖安装，无需卸载。

    Install
    $ adb install -r app-debug.apk
    1. 环境：JDK 17、SDK 平台 android-37.0（注意不是 android-37）。
    2. 授权：cmdline-tools 下工具默认无可执行位，先 chmod +x。
    3. 编译：首次会拉依赖，缓存目录锁告警属收尾噪音。
    4. 校验：apksigner verify 与 aapt2 dump badging 核对版本与证书。

    08

    问答

    五条，都是改动过程中真实出现过的疑问。

    删除的是第三方账户系统（LastStudio / FE 账户那一套），ETS100 自己的账号体系必须保留，否则云端 API 无法取到 token。 第一版改造误把它简化成了跳转页，后续从原始工程恢复为原生表单。
    是。三种本地模式都依赖设备权限或在本地解析答案文件，而云端链路本身已经能返回完整答案， 多一条本地路径只增加权限申请与失败分支，因此整条删除。
    不会。新旧包同为 Android Debug 证书、applicationId 相同、versionCode 递增， adb install -r 覆盖安装即可保留设置与登录状态。只有签名不一致时才需要卸载。
    animateFloatAsState 返回的是普通 Float，在 graphicsLayer 的 lambda 里读它会把整个 Composable 拉进组合阶段， 每帧一次重组。换成 Animatable 后读 .value 只触发 draw，跳过组合与布局。
    原始项目声明闭源并禁止重新打包分发，本仓库是其本地改造版本，仅供个人学习与备份。 若要二次分发，需自行取得原始作者授权；页面与仓库不再附带原始营销文案与私域信息。
